# The feedback chain

Satisfaction does not come from one mechanic. It comes from an unbroken chain
in which each step visibly causes the next.

## Principles

1. **Keep the chain continuous.**

       intention -> immediate response -> clear attack motion
         -> visible impact on the enemy and the world
         -> death and its aftermath -> sound and screen response
         -> loot burst -> item appraisal -> a stronger or altered build
         -> faster, more spectacular combat

   A missing link is felt even when every other link is good. Find the weakest
   link and fix that before polishing a strong one.

2. **Nothing just loses health and vanishes.** An enemy is hit, staggers, is
   knocked back, dies loudly, leaves something behind. The game keeps
   confirming that what happened changed the world.

3. **Reward at every time scale.** Each scale needs its own payoff, and each
   payoff should point at the next scale up.

   | Scale | Payoff |
   | --- | --- |
   | Milliseconds | An action starts the moment it is asked for |
   | Seconds | A group dies, a chain reaction, drops are collected |
   | Minutes | An objective or a stage is completed |
   | Tens of minutes | A run ends with its own reward |
   | Hours | A build comes together and changes what the character can do |
   | Long term | Restart, experiment, optimise, push a new benchmark |

4. **Power must show.** A stronger build should make combat look and sound
   different, not only move a number. That is what closes the loop.

## For Horse Heroes

- The party fights by itself, so "intention" is mostly the player's choices in
  camp (element, gear) and the horses' own abilities. The chain starts at the
  attack motion. It is no excuse for a weaker chain: an idle game is watched,
  so the watching has to be worth it.
- The same rule applies to the horses. A horse that is hit should show it; a
  horse that falls should not simply disappear.
- Mapping the scales: seconds = one encounter; minutes = one trail and its
  final enemy; tens of minutes = a few trail levels and a gear set taking
  shape; hours = a party build. A scale with no payoff is a gap to file as an
  issue.
- Pillar 2 still holds: every link must play out with no input.
